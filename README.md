# Student Result Prediction using SVC and Logistic Regression

## Project Overview
This is a beginner-level Machine Learning practice project using student data.

The objective is to predict student results based on study hours, attendance percentage, and previous scores using classification algorithms.

## Dataset Information
- Total Records: 500
- Total Columns: 4
- Missing Values: 0

### Dataset Columns
- Study_Hours
- Attendance_Percent
- Previous_Score
- Result (Target Variable)

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load the dataset
2. Understand the dataset using info() and describe()
3. Check missing values
4. Analyse the target variable
5. Visualize pass and fail counts
6. Separate features and target
7. Split data into training and testing sets
8. Apply StandardScaler
9. Train the SVC model
10. Make predictions and evaluate accuracy
11. Build a Pipeline using StandardScaler and Logistic Regression
12. Compare training and testing accuracy

## Machine Learning Algorithms

**1. Support Vector Classifier (SVC)**
- Kernel: Linear
- C: 1
- Testing Accuracy: 100%

**2. Logistic Regression**
- Used with StandardScaler in a Pipeline
- Training Accuracy: 98.75%
- Testing Accuracy: 100%

## Learning Outcomes
- Understanding classification problems
- Learning SVC and Logistic Regression
- Applying feature scaling
- Using train-test split with stratification
- Building a Machine Learning Pipeline
- Making predictions and evaluating model accuracy
